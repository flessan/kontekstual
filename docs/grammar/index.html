REFERENSI BAHASA · 01

Tata bahasa
dan sintaks.

Kontekstual memakai kata kunci eksplisit berbahasa Indonesia. Bahasa ini bukan pemroses kalimat bebas; instruksi harus mengikuti pola sintaks yang didefinisikan.

DI HALAMAN INIInstruksiKomentarVariabel dan nilaiKondisiPerulanganIndentasi
01 / BENTUK DASAR

Setiap instruksi berakhir dengan titik

Tanda titik (.) menjadi penanda akhir sebuah instruksi. File program berakhir ketika seluruh isi file selesai dibaca; tidak perlu pembungkus awal atau kata penutup buatan.

Tampilkan teks "Halo dunia!".
Tetapkan umur bernilai 20.
Tampilkan umur.
IngatTeks harus ditulis di antara tanda kutip. Kata di luar kutip dapat ditafsirkan sebagai nama variabel atau bagian sintaks.
02 / KOMENTAR

Komentar satu baris atau beberapa baris

Komentar dimulai dengan {- dan berakhir dengan -}. Komentar tidak dijalankan sebagai instruksi program.

{- Catatan untuk pembaca -}
Tampilkan "Halo".

{-
Komentar dapat menjelaskan
tujuan bagian program ini.
-}
03 / NILAI

Deklarasi dan perubahan variabel

Gunakan Tetapkan untuk memperkenalkan nilai. Bentuk ringkas bernilai maupun bentuk eksplisit dengan nilai diterima oleh interpreter.

Tetapkan nama bernilai "Thio".
Tetapkan umur dengan nilai 20.
Tetapkan aktif bernilai benar.
Ubah umur menjadi umur + 1.

Nilai yang tersedia pada interpreter saat ini mencakup angka bulat, teks, dan logika. Nilai logika ditulis benar atau salah.

04 / KONTROL ALUR

Kondisi memakai indentasi

Bagian setelah maka: ditulis pada baris berikutnya dan menjorok ke dalam. Cabang alternatif memakai Jika tidak, maka: pada tingkat indentasi yang sama dengan Jika.

Jika umur lebih dari atau sama dengan 18, maka:
    Tampilkan "Dewasa".
Jika tidak, maka:
    Tampilkan "Belum dewasa".
Tampilkan "Selesai memeriksa".

Blok kondisi berakhir ketika indentasi kembali ke tingkat sebelumnya atau file selesai. Tidak ada kata penutup blok yang wajib ditulis.

05 / PERULANGAN

Selama mengulang saat kondisi benar

Kondisi diperiksa sebelum setiap iterasi. Pastikan isi blok mengubah nilai yang diperlukan agar kondisi pada akhirnya menjadi salah.

Tetapkan hitungan bernilai 1.
Selama hitungan kurang dari atau sama dengan 3, lakukan:
    Tampilkan hitungan.
    Ubah hitungan menjadi hitungan + 1.
Batas keamanan runtimeInterpreter dan playground membatasi total iterasi perulangan agar program eksperimen tidak berjalan tanpa batas.
06 / STRUKTUR

Indentasi adalah bagian dari sintaks

Gunakan empat spasi untuk isi blok agar kode mudah dibaca. Formatter dapat merapikan sebagian indentasi berdasarkan indentasi sumber yang ada, tetapi tidak selalu bisa menebak batas blok jika seluruh informasi indentasi hilang.
