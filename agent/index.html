02 / ALUR PEMBUATAN PROYEK

Prosedur yang dianjurkan untuk agent

  1. Baca sumber otoritatif.Mulai dengan llms.txt, lalu spesifikasi dan docs grammar. Jangan menyimpulkan kemampuan dari nama bahasa.
  2. Batasi sintaks ke fitur yang didukung.Pilih perintah, tipe nilai, kondisi, dan loop yang sudah ada di interpreter. Tandai sintaks yang belum terimplementasi sebagai usulan.
  3. Buat contoh terkecil yang valid.Setiap instruksi berakhir dengan titik; teks memakai tanda kutip dan blok memakai indentasi.
  4. Validasi lewat tool yang tersedia.Untuk repository checkout, jalankan cargo test dan contoh cargo run. Untuk browser playground, gunakan pnpm test dan pnpm build.
  5. Laporkan perbedaan runtime.Rust menggunakan signed 64-bit integers; interpreter browser berbasis JavaScript memiliki batas safe integer.
03 / RULES OF ENGAGEMENT

Aturan penting saat menghasilkan kode

01

Jangan membuat sintaks penutup blok seperti Selesai jika.. Blok selesai berdasarkan indentasi.

02

Gunakan kata kunci sesuai ejaan sintaks yang terdokumentasi, misalnya Tetapkan, Tampilkan, Ubah, Jika, dan Selama.

03

Jangan mengklaim fitur fungsi, modul, input interaktif, atau kompilasi executable native sudah tersedia.

04

Untuk error, sertakan program minimal yang memicu error serta hasil tes. Hindari mengubah grammar berdasarkan asumsi.

04 / VALIDASI

pnpm install --frozen-lockfile
