02 / ALUR PEMBUATAN PROYEK

Prosedur yang dianjurkan untuk agen

  1. Baca sumber otoritatif.Mulai dengan llms.txt, lalu spesifikasi dan dokumentasi tata bahasa. Jangan menyimpulkan kemampuan dari nama bahasa.
  2. Batasi sintaks ke fitur yang tersedia.Pilih perintah, tipe nilai, kondisi, dan perulangan yang sudah ada di interpreter. Tandai sintaks yang belum terimplementasi sebagai usulan.
  3. Buat contoh terkecil yang valid.Setiap instruksi berakhir dengan titik; teks memakai tanda kutip dan blok memakai indentasi.
  4. Validasi lewat alat yang tersedia.Untuk salinan repositori lokal, jalankan cargo test dan contoh cargo run. Untuk playground di peramban, gunakan pnpm test dan pnpm build.
  5. Laporkan perbedaan batas implementasi.Rust menggunakan bilangan bulat bertanda 64-bit; interpreter peramban berbasis JavaScript memiliki batas bilangan bulat aman JavaScript.
03 / ATURAN PENTING

Aturan penting saat menulis kode

01

Jangan membuat sintaks penutup blok seperti Selesai jika.. Blok selesai berdasarkan indentasi.

02

Gunakan kata kunci sesuai ejaan sintaks yang terdokumentasi, misalnya Tetapkan, Tampilkan, Tanyakan, Ubah, Jika, dan Selama.

03

Gunakan `Tanyakan "pertanyaan?" dan simpan sebagai nama.` untuk masukan teks satu baris. Konversi tipe masukan, fungsi, modul, dan kompilasi program biner mandiri belum tersedia.

04

Untuk kesalahan, sertakan program terkecil yang memicunya serta hasil pengujian. Hindari mengubah tata bahasa berdasarkan asumsi.

04 / VALIDASI

Perintah untuk menjalankan pemeriksaan di repositori

pnpm install --frozen-lockfile
pnpm test
pnpm build

cargo test --all-targets
cargo run -- check examples/halo.konteks
cargo run -- run examples/halo.konteks

Situs dan playground di peramban ini dibuat untuk belajar. Interpreter Rust tetap menjadi acuan utama untuk memvalidasi perilaku bahasa saat ini.
